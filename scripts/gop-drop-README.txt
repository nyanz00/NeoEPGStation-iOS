GOP測定JSON作成（Windows用）

使い方
1. 動画ファイルを「GOP測定JSON作成.cmd」へドラッグ＆ドロップします。
   デスクトップに「GOP測定JSON作成」ショートカットを置いた環境では、そこへドロップできます。
   複数動画や、動画の入ったフォルダーもドロップできます。
   フォルダーの中のサブフォルダーは対象外です。
2. 解析と画像照合データの準備を待ちます。動画の長さによって数分かかります。
3. 動画と同じ場所に、動画ごとの gop-seek-plan-*.json が作成されます。
   同名ファイルがあれば番号を付け、既存のJSONは上書きしません。
4. iPhoneの「ファイル」に動画と対応するJSONを同じフォルダーへコピーします。
5. アプリの「設定→視聴→GOPシーク測定（ローカル）」で、その2ファイルを選択します。
   ビルド355で使えます。連続切り替えの不調を避け、1本ずつ測定してください。
6. 測定ごとに結果を共有・保存してください。次の測定を始めると結果が置き換わります。

測定位置
動画内に均等に配置した8つの時間帯から、キーフレーム区間を1つずつ選びます。
各区間の近・中央・遠の3地点へ送り・戻しを測ります。1周48回＋ウォームアップ2回です。
測定判定の許容幅が隣のGOPに入らないよう、近・遠には3フレーム程度以上の余裕を取ります。
近・中央・遠の判定範囲を分離できない短い区間は選択しません。
各地点は映像パケットPTSから選びます。乱数は使いません。
GOP設定によって絶対時刻は変わります。以前の同時刻・乱数方式の結果とは分けて集計します。
計画JSONのsampling.pointsに近・中央・遠の区別を保存します。
現行アプリの画面・結果JSONにはこのラベルは表示されないため、計画JSONも保存してください。

準備
Python 3とFFmpeg/ffprobeが必要です。追加のPythonパッケージは不要です。
ffmpeg.exeとffprobe.exeはPATH上、またはこのツールと同じフォルダーへ置いてください。
対応コンテナはMKV/MP4/MOV/M4Vです。参照画像はSDRのBT.709/色指定なしの動画に対応します。
60秒以下の動画や、測定用の区間数を確保できない動画はエラーになります。
動画を変更・再エンコードしたり、ネットへアップロードしたりする処理はありません。

移動する場合
GOP測定JSON作成.cmd、gop_drop.py、gop_reference.pyの3ファイルを一緒に移動してください。

コマンドから使う場合（区間数は1〜16、既定8）
python gop_drop.py --sections 8 "動画のパス"
python gop_drop.py --check "動画のパス"
--checkは測定位置の確認だけで、画像照合データやJSONは作成しません。
