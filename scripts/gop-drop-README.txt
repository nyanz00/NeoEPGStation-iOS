GOP測定JSON作成（Windows用）

使い方
1. 動画ファイルを「GOP測定JSON作成.cmd」へドラッグ＆ドロップします。
   デスクトップに「GOP測定JSON作成」ショートカットを置いた環境では、そこへドロップできます。
   複数動画や、動画の入ったフォルダーもドロップできます。
   フォルダーの中のサブフォルダーは対象外です。
2. キーフレームと映像パケットの時刻を解析します。参照画像の作成・動画の復号は行いません。
3. 全動画の解析後、先頭の動画と同じ場所に統合した gop-seek-plan.json が1個作成されます。
   同名ファイルがあれば番号を付け、既存のJSONは上書きしません。
   失敗した動画があれば部分的なJSONは保存しません。
4. iPhoneの「ファイル」に動画とこのJSONを同じフォルダーへコピーします。
5. 修正版アプリの「設定→視聴→GOPシーク測定（ローカル）」で、JSONと測定したい動画をまとめて選択します。
   このschema 2軽量形式はビルド356以降に対応します。ビルド355では使えません。
   同じプレイヤー内で入力を切り替え、選択した動画を順番に測定します。
6. 終了後に結果を共有・保存してください。全動画の結果は1個にまとまります。
   動画ごとの完了時にも保存します。新しい測定を始めると結果は置き換わります。
   測定中はアプリを前面に置き、プレイヤーを操作しないでください。

測定位置
動画内に均等に配置した8つの時間帯から、キーフレーム区間を1つずつ選びます。
各区間の近・中央・遠の3地点へ送り・戻しを測ります。1周48回＋ウォームアップ2回です。
測定判定の許容幅が隣のGOPに入らないよう、近・遠には3フレーム程度以上の余裕を取ります。
近・中央・遠の判定範囲を分離できない短い区間は選択しません。
各地点は映像パケットPTSから選びます。乱数は使いません。
GOP設定によって絶対時刻は変わります。以前の同時刻・乱数方式の結果とは分けて集計します。
計画JSONのprofiles[].targets/pointsに動画別の位置と近・中央・遠の区別を保存します。
結果にもgroup/sectionを転記し、summaryByGroupに区分別の集計を保存します。
測るのは目的時刻の表示用映像バッファを確認するまでです。エンジン完了通知とは別に記録します。
画像の表示時刻が取れない再生経路では、軽量計画の測定を中断して理由を記録します。

準備
Python 3とffprobeが必要です。追加のPythonパッケージとffmpeg本体は不要です。
ffprobe.exeはPATH上、またはこのツールと同じフォルダーへ置いてください。
対応コンテナはMKV/MP4/MOV/M4Vです。一度に12本まで、ファイルサイズの重複は区別できません。
60秒以下の動画や、測定用の区間数を確保できない動画はエラーになります。
動画を変更・再エンコードしたり、ネットへアップロードしたりする処理はありません。

移動する場合
GOP測定JSON作成.cmdとgop_drop.pyを一緒に移動してください。

コマンドから使う場合（区間数は1〜16、既定8）
python gop_drop.py --sections 8 "動画のパス"
python gop_drop.py --check "動画のパス"
python gop_drop.py --output "出力先.json" "動画のパス1" "動画のパス2"
--checkは測定位置の確認だけで、JSONは作成しません。
