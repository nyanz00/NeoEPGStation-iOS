# 実キーフレーム間へのチェックポイント挿入（PC実験）

同じAV1入力・同じ目的画像に対して、次の3方式を比較する。

1. チェックポイントなし：直前の実キーフレームから復号。
2. 固定配置：時刻6/12/18…秒のパケット境界に保存。直前のキーと保存地点のうち新しい方から復号。
3. 中間配置：隣り合う実キーフレームの時刻の中間以上となる最初のパケットの直前まで復号し、状態を保存。
   シーク時は直前のキーか、この保存地点から復号する。

元動画を変更せず、先頭63.330秒を含む区間だけcodec copyでIVF化した。
1440×1080、AV1 Main、10bit、VFR。全編のキー間隔の中央値は6.006秒、範囲2.402〜6.039秒。
先頭のキー時刻は0/4.062/9.276/15.282…秒であり、6の倍数に揃ってはいない。
元ファイルの名前・パス・映像・音声はリポジトリに含めない。

## 条件と確認

- dav1d 1.5.4（既存実験と同じ固定リビジョン）。6ワーカー、自動フレーム並列度3。
- 前の並列チェックポイント実験のcore/packed/streaming feederを再利用。
- 6個の物理コアに固定し、初期化済みの復号器を再利用。方式ごとに比較用の復号器を1つ用意する。
  保存地点ごとに復号器を追加する構成ではない。計測中に動かすのは1方式だけ。
- 11個の完全なGOP。各GOPの10/40/51/75/95/99%付近、計66位置。VFRで99%位置に画像が
  存在しない場合は、次のキーを越えずにそのGOPの最後の実パケットを使う。
- 各目的位置を各方式5回、方式と目的位置の実行順をローテーション。合計990回。
- チェックポイントは計測前に作成し、同時に保持。10bit無損失パック、元の画像参照は保持しない。
  保存時に余白を含むアロケーション全バイトの一致を確認。
- 保存なしはflush開始、中間/固定配置はrestore開始から目的画像が返るまでを計時。
  復元・展開・flushのコストを含める。シーク先が保存地点より前ならキー経路を使う。
- 通信、準備復号、保存作成、音声、UI、画面表示、画素比較はシークタイマーの外。
  入力はRAM。途中フレームのスキップなし。
- 別の単一スレッド復号器が先頭から通常復号した画像を正解とし、全990回で全Y/U/V有効画素・
  形式・PTS・入力対応が一致。復号器を閉じた後、保存状態を逆順に解放。

この位置の選び方はGOP後半を多めに含む。下記は選んだ位置集合の統計であり、
一般的な視聴操作の時間分布や、iPhoneアプリの映像・音声再開時間を測ったものではない。

## 結果

各方式330回の生値は `results.json`。95%点は生値をソートして線形補間した参考値。

| 方式 | 中央値 | 95%点 | 観測最大 | 保存地点 | 保存状態の容量合計 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 保存なし | 124.1ms | 272.7ms | 317.7ms | 0 | 0 |
| 6秒ごとの固定配置 | 70.0ms | 151.8ms | 173.0ms | 10 | 180.6MiB |
| 実キー間の中間配置 | 63.4ms | 137.4ms | 171.4ms | 11 | 198.6MiB |

中間配置は保存なしに対して中央値約49%、95%点約50%、観測最大約46%短縮。
固定配置に対しては中央値約9%、95%点約9%短縮、観測最大の差は約1.6ms。
各目的位置で5回の中央値を取ってから集計しても、全体中央値は124.0/70.8/62.9ms。

中間より前の位置では、中間方式もキーから再開するので中央値52.2/52.6msでほぼ同等。
中間以降では保存なし153.5msに対して中間方式68.9ms。
保存処理自体の中央値5.56ms、保存前の残り出力待ち中央値1.07ms（いずれも別計測）。

1地点の保持量は約18.06MiB。容量合計は各地点の保持量の単純合計であり、プロセス使用量ではない。
短い冒頭GOPにも1地点挟んだため、中間方式は固定方式より1地点多い。配置だけを変えて
同じ地点数に固定した試験ではない。また、この標本では9.276秒以降のキーに対して
6秒固定配置も中間に比較的近く、配置を合わせる上積みが小さくなる条件だった。
全編の他の位置や、より長いGOPにこの差をそのまま当てはめない。

## 再実行

Windows、Python、FFmpeg/FFprobe、MSYS2 MinGW64が必要。
既存のMT実験で準備した `.local/dav1d-mt` を再利用し、固定リビジョン・ソースを照合/再配置する。

```powershell
python experiments/dav1d-midpoint-checkpoint/run.py --input 'ローカルのAV1動画.mkv'
```

入力ファイルを変更せず、`.local/` にIVFと実行ファイル、実験フォルダに匿名化した測定値を出力する。
アプリ本体・通常プレイヤー・Actionsの変更は行っていない。
