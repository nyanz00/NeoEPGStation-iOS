## 実装

Webの`useTouchPlayerControls.ts`は背景タップで操作欄を切り替え、後続クリックを止める。
ネイティブ版ではVLCから追加される映像出力ビューのタッチ受付を無効にして、
共通祖先にあるアプリ側の認識器へまとめた。VLCの出力ビューはタップをmouseイベントへ転送するため、
TS等の出力で再生・一時停止が発生し得る。リロードで出力が置き換わる場合にも適用する。
表示切り替えは再生状態を変更せず、中央の再生ボタンは従来どおり再生・一時停止を操作する。

プレイヤーに通常画面と共通の40％／60％の判定を使う右方向のスワイプを追加した。
縦画面の上40％はサイドメニュー、下60％は録画詳細への戻り。横画面では全領域がサイドメニュー。
縦スクロール・横スクロール・スライダー・スイッチと区別し、開始時の領域で操作を固定する。
メニューは指に追従し、戻るは完了時だけ実行する。キャンセルではプレイヤーに残る。

PiPの`pip.enter`は最大寸法を20ptから24ptへ20％拡大した。
縦画面では設定パネルの閉じるボタンを隠す。横画面の字幕タブの上の位置は維持する。
全般設定の一番下へ動画の再読み込みボタンを復活させ、コメント・字幕設定には追加しない。
コメント表示・サイズ・不透明度はUserDefaultsへ保存し、新しいプレイヤーの生成時にも読み戻す。
通常画面とPiPの合成は同じ設定値を使う。
