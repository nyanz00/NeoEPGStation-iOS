# 通常字幕・ページ切り替え・戻る時間

## 対象と成功条件

- 通常ページの戻るボタンとスワイプ、プレイヤー終了、履歴への戻りを150ms基準へ統一する。ドラッグ中の進捗追従とキャンセルは保持する。
- エンコード済みPLAY/STREAMINGの通常ASS/SRTはWebの`CanvasSubtitleLayout.ts`、`CanvasSubtitleRenderer.ts`、`subtitleFont.ts`を基準とする。実況コメントとTS/ライブのARIBは変更しない。
- 通常字幕のフォントをiOSのWebと同じ丸ゴシック系から選び、利用できなければ日本語sans-serifへ落とす。AmatsukazeのYu Gothic 46px補正、SRTの正方画素レイアウト、元の位置・時刻・装飾を維持する。
- 半透明の背景を文字と分離し、同色背景の重なりで濃くしない。近接するルビは同一表示区間・レイヤーであることを確認できる場合に背景を接続する。
- VLCとAetherの通常字幕を共通libass描画へ接続する。VLCの元トラックとの二重表示を抑止し、画面と合成PiPで同じサイズの描画キャッシュを使用する。
- 複数レイヤーは各レイヤーの背景→文字の順で合成する。可視レイヤーだけレンダラーを作り、非表示の保持キャッシュは最大4件とする。先の全レイヤーを先行生成しない。
- 「表示」に上部ページ切り替えと拡張ページ切り替えを別々のスイッチとして追加する。初期値はオフ、下部は残す。フィルター・並び順・表示件数はページ移動で保持する。
- 拡張時は現在番号のタップで番号入力、範囲外・非整数入力では移動不可とする。既存の5番号・前後ボタンを縮めず、両端の余白に収まる場合だけ先頭・末尾を追加する。回転後も実幅で再計算する。

## 検証範囲

Foundationのモデル試験で番号入力と字幕の書式・位置・タイミング保持を確認する。両SDKをビルドし、iPhone/iPadの対象画面試験で上部表示のオンオフ、番号入力、狭幅・広幅のボタン操作を確認する。

同じ実アプリで通常字幕を描画し、キュー終了後の消去、白文字と半透明背景の画素、背景重複時の濃さ、画面/PiPサイズ間の画像再利用を確認してPNGを残す。戻るの完了・キャンセル・指追従は対象のナビゲーション試験で確認する。無関係な全再生経路の総当たりは追加しない。

libassとブラウザーCanvasは字形計測・ラスタライズの実装が異なるため、ピクセル単位の同一性は主張しない。抽出に失敗した場合の元エンジンの字幕表示はフォールバックであり、共通スタイル適用の成功とは扱わない。

## 確認結果

- ビルド346、アプリソース`a368c88`、Actions `42266303461`。実機・シミュレーター両SDKのビルドとモデル46項目は成功した。
- iPhoneは対象画面89/89、戻る操作47/47。iPadは対象画面88/89、戻る操作47/47。通常字幕の半透明背景・重複とレイヤー順、Aetherの画面/PiP合成先への受け渡し、字幕オフ、上部ページ操作・番号入力・幅による端ボタンの省略は両端末で成功した。保存した字幕・ページ操作の画像も確認した。
- 残件は既存のiPad初回全般画面の開始応答100ms基準のみで、今回は123.6msだった。先行ビルド345でも121.0msで未達だったため、同じ条件の再試験は追加していない。この基準は未達のまま記録し、Actions全体を成功とは扱わない。
- Aetherの確認は共有レンダラーと実バックエンドの画像受け渡しであり、動画を再生しながらの実機PiP確認とは区別する。実録画のASS/SRTの見え方は実機確認が残る。
- IPAは`NeoEPGStation-build346.ipa`、SHA-256は`5b22c28e2e471be807861e84e9e82091e3e81e4886444954e568b264412992b6`。取得したアーカイブ・IPAのダイジェスト、ビルド番号、ソースコミットを照合した。
