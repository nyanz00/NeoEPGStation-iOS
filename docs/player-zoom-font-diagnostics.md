# ピンチ操作とコメントフォント診断

## 変更範囲

- コメントの指定フォントと、Core Textで文字を組んだ後の実使用フォントを記録する。日本語／英数字の代替先、PostScript名・ファミリー・太字・斜体・ウェイトを確認できる。フォント自体は変更しない。
- 記録は文字画像の準備時に行い、毎フレームの処理には加えない。診断JSONの `commentFonts` に重複を除いて最大64件保存し、イベント履歴が一巡しても保持する。次の再生でリセットする。コメント本文は保存しない。
- 拡大開始は減衰させないUIKitのlight、元のサイズへの復帰・1倍での縮小操作はheavy。Core Hapticsは弱い余韻だけを追加する。拡大側28ms、復帰側55ms。指を離した時には発火しない。
- 倍率は指の間隔の変化へ直接対応させる。開始間隔をd、動画表示領域の高さをHとしたとき、1ポイント当たり `7 / max(H-d, H*0.25)` 倍変化させる。1倍から中央付近で開始し、上下端まで広げると8倍になる。開始間隔が広すぎる場合は過敏にならないよう制限する。
- 倍率は1〜8倍。上限・下限で指を動かし続けても前回の間隔を更新し、逆方向へ動かした瞬間から反応する。映像以外のUI・コメント・PiPの拡大は変更しない。

## 検証方法

Actionsの `check_scope=zoom-font` で型検査・ビルドと、実際のReleaseアプリ内のピンチ／触覚発火条件／文字描画経路のフォント記録を確認する。回転・ネットワーク・ARIB・全体UI試験はこの範囲では実行しない。

対象試験の結果は `player-zoom-font-smoke.json`、描画経路から得たフォント名は `font-diagnostics.json` に保存する。シミュレーターのフォント名は実機のフォント名の証明には使わない。実機の名前は、該当コメントを表示してからアプリの再生診断JSONを保存して確認する。

触覚の強さ・余韻と操作の感触は実機確認が必要。
