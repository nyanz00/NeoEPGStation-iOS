# 録画画面の応答・Info・Annict

## 対象と成功条件

- 開く動きを150msに短縮する。初回の設定・録画詳細をviewDidLoadとviewWillAppearの両方で全生成しない。録画一覧は画像準備の最大400ms待ちを外し、セルの既存非同期・共有サムネイル取得を使う。一覧自体のWeb準拠フェードは維持する。
- WebのRecordedItemActions.tsx / VideoInfoView / KeyframeIntervalInfoと同じ全21行（基本12・キー統計7・日時と状態2）と推定表記を表示する。未対応サーバーでは基本情報を表示し、キー解析の未対応を明示する。ファイル切替・POST再解析・pending/analyzing中の3秒ポーリング・stale結果維持・更新失敗時の既存結果維持に対応する。
- WebのRecordedDetailPage、RecordedWatchPage、api/annictEpisode.ts、storage/settings.tsを基準に、再照合・記録・所有記録の削除確認・保留状態と理由・ユーザーとロック済みプロフィール認証を引き継ぐ。
- Annictタブには読み取り/書き込み連携状態とサーバー保存のトークン設定、自動記録3方式、割合1〜100（既定90）、最終話の作品視聴済み化（既定オン）、それに連動した所有ルールの無効化（既定オン）を置く。最終話判定・ルール所有者や残予約・Annict記録の所有権は既存サーバーAPIが判定する。アプリにトークンを永続保存しない。
- VLC/Aether共通の録画プレイヤーから実再生開始と累計を受け取る。シーク・一時停止・バッファリングは視聴時間に加算しない。サーバーの累計視聴時間に未送信の現在セッション分を合わせて判定する。履歴送信をオフにした場合は、既存累計＋端末内の実視聴分で判定し、履歴送信は行わない。
- 重複書き込みを抑止し、失敗時はWebと同じ60秒間隔で再試行する。閉じる時点で記録条件を満たした送信は完了させる。プロフィール変更時は保留処理を取り消し、送信時の認証ヘッダーも固定して別プロフィールへ書き込まない。Annictの障害で再生を止めない。
- 未移植のダウンロード・ルール編集・アニメ作品画面固有の設定は、今回の録画視聴連携には含めない。

## 検証

`check_scope=player-feedback, ui_stage=recording-features`を用いる。FoundationでInfoの全項目・null/旧サーバー・stale/エラー・Annict既定値/割合/最終話オプション・シーク除外を検証する。

iPhone/iPadではURLProtocolによる合成APIを実際のNeoAPI・Infoダイアログ・設定コントロール・詳細ヘッダー・自動記録送信器に接続する。認証、トークンのサーバー送信、手動記録/取消/外部記録の保護、再照合、自動記録の重複抑止・累計割合・再試行・終了後送信・プロフィール変更時の取消、Infoの全行・ファイル切替・ポーリング・再解析・エラー時の結果維持、初回生成回数を確認する。実サービスへ視聴記録やトークンを書き込む試験ではない。

Swift/Objective-Cの共通接続は両SDKの実ターゲットビルドで検証する。実機での操作感、実際のAnnict連携、バックグラウンド/PiP中の実再生は別途実機確認が必要。

## 表示・切替の追加修正

- タップ操作のスクロール判定待ちを設定一覧・録画一覧・サイドメニュー・設定内ボタンから除く。スワイプ判定とキャンセルは維持する。pushは150msのままease-outとし、詳細の再取得・Annict取得をviewDidAppearへ移す。最初は一覧から渡された情報を表示する。iPad幅での初回の二重構築も避ける。
- シミュレーターでは設定一覧の実選択ハンドラーと録画詳細の実入口から、構築・push復帰・animator開始・presentation layerの最初の移動を分けて数値化する。`ui-*-recording-opening-times.json`へ保存する。物理タッチのOS配信時間や実機の体感を、この内部計測だけで確認済みとはしない。
- Annictのトークン行はWebのSettingsPage／MUIのdark paletteを参照する。小さいoutlined入力＋ContentPasteOutlined＋接続＋解除を横並びにし、接続は空白入力・通信中・権限なしで無効。無効文字は白30%、背景は白12%、解除はerror.main（`#f44336`）で接続済みの時に表示する。
- InfoはWebと同じ横並び・8pt間隔・折返し。未取得への切替でも直前の本文高さを下限として維持し、他ファイルの情報を表示せず取得中を示す。取得結果はアニメーションなしで入れ替える。閉じるボタンは「閉じる」。
- 合成APIの応答遅延を使い、切替中の高さ維持と誤表示防止、長いファイル名の折返し、空白／入力／通信中／接続済みのトークン操作を追加検証する。画像はpresented dialogを含むwindow全体から取得する。

- ビルド322では他の34項目は成功したが、視聴設定の初回移動1933msで追加の性能条件が失敗した（構築3ms、render 80ms、animator開始118ms）。行の独立配置だけでは解消できなかったため、視聴設定はUITableViewで可視行だけを階層へ配置する。画面外の設定も値とイベントは保持し、スクロールで必要な時に同じ操作部品を取り付ける。画面幅変更時は行高さを再計算し、スクロール終端まで全項目に到達できることも検証する。
