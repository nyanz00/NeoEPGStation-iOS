# Swift / UIKit移植の検証

- アプリのコミット: `ad084271276965077b97c01a227be8775fd1ddb3`
- 検証ビルド: 32 / iOS最低バージョン18.0 / VLCKit 4.0.0a25
- [Actionsのビルドと成果物](https://github.com/nyanz00/NeoEPGStation-iOS/actions/runs/37221456141)
- バンドルIDは維持。React Native / JavaScriptの実行環境は含めない。

## 確認済み

Swiftの型検査、ASS・再生時刻の既存テスト、ページ番号・URL正規化・日時・
録画データのテストを通過した。URLProtocolによる通信テストではサブパス、
検索文字、ページ位置、新しい録画からの順序、HTTPエラー、非JSONの応答と
録画IDの不一致を確認した。実際のKeychainとUserDefaultsで保存・旧設定の
読み戻し・不正なナビゲーション設定の拒否も通過した。

実機用IPAとシミュレーター用Releaseアプリをビルドした。
シミュレーターではVLCのテスト動画再生、映像フレーム取得、コメント合成、
横画面の既存チェックが通過した。

iPhoneの一覧・ページ7・詳細・メニュー・設定、iPadの一覧・詳細を画像で確認した。
一覧はタブ移動の前後で同じ画面インスタンスを保持する。
108ptのモバイルカードと、ページ7の `5 6 7 8 9` の表示を検証した。
スクリーンショットはシミュレーター専用の架空データを使い、実サーバーの情報を含めない。

## 実機で確認する内容

- 既存アプリを同じバンドルIDで更新し、保存済み接続先から自動で接続できること。
- メニューの指への追従、タブ切り替え、下半分からの戻るスワイプ、一覧の位置保持。
- 実サーバーで検索・ページ移動・詳細取得・ファイル選択からPLAYを開始できること。
- LiveContainer上で、既存のコメント付きPiPへ移行・復帰できること。

シミュレーターではPiPの合成処理を検証するが、実際のPiP小窓の開始はサポートされない。
実機の操作性能とAV1ソフトウェアデコード性能は、この検証の成功だけでは確定しない。
高度な検索条件・ユーザー選択・録画管理・STREAMING・放映中などは後続の移植対象。
