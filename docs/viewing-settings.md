# 視聴設定と放映中操作の整理

- Web参照はSettingsPage、storage/settings、media/live・recorded・subtitlesと両配信選択ダイアログ。通常字幕は優先語に一致しなければオフ。弾幕は優先語、保存した選択、先頭の順で選ぶ。配信ダイアログでの明示選択は優先する。
- 設定カテゴリーの副説明を削除。Annict・Discordは空の画面への入口だけ追加し、外部連携や通知送信は追加しない。
- 再生エンジンとチェックポイントは既存キーのまま視聴へ移動。アプリ設定には接続先と下部ナビゲーションを置き、文字ラベルのオン／オフを保存する。
- エンコーダーはConfigで要求を省略し、それ以外は選択値を送る。画質はグローバル指定が有効なら保存したモードより優先。低遅延はライブの初期ストリーム種別を決める。HEVCと録画STREAMINGの開始バッファ3セグメントを実要求へ渡す。
- 字幕の優先語は最大3個で、順序・空欄除外・大文字小文字を無視した部分一致・displayName/title/language/codecNameの照合をWebから引き継ぐ。弾幕と通常字幕を別々に選ぶ。TSのARIBオン／オフは維持する。
- 準備待ちは既存のplayer.comments.waitBeforePlaybackを共有。PLAYではコメントと選択した通常字幕の準備を待つ。通常字幕の取得失敗・該当なしでも待機を解除する。
- PLAYのネットワークキャッシュは初期化の固定5秒を廃止し保存値を使う。巻き戻し、STREAMING先読み・巻き戻し、コメントサイズ・不透明度も既存プレイヤーのキーを共有。コメントの変更はPiP等で既存の描画器が生存していても反映する。キャッシュは次の再生・再読み込み時に適用する。
- 放送波を確定した際に一覧を横スライド。取り消しと先頭波でのメニュー操作を維持。長い番組名は表示中だけ往復スクロールし、定期更新では再開始しない。収まる文字・非表示・動作軽減設定では動かさない。
- メニューが閉じる際、背景が透明化する途中も新ページのタッチを遮断していた。閉じ始めで背景の入力を無効化し、アニメーション中の入力を許可する。実際のナビゲーション遷移中の二重操作防止とタブ間の戻る制限を維持する。

対象検証はplayer-feedback。Foundationでは設定の保存・初期値・設定優先順位・メタデータ照合を確認。iPhone/iPadでは設定からプレイヤーへの値伝搬、空カテゴリー、文字ラベル、閉じる途中の背景、配信要求のqueryを確認。ライブ試験では波の切り替えアニメーションと長い番組名の動作を追加する。
