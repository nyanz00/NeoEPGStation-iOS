## 変更

ユーザー指定により、流れるコメントが右端から左端外まで移動する時間を縦横とも5.25秒にする。
`CommentTiming.scrollingDuration` は通常描画、行配置、PiP合成で共通使用する。
固定コメントの表示時間は従来の4.5秒を維持する。

アプリ設定の「視聴履歴のユーザーを選択」を維持し、候補の先頭に「master（すべて）」を追加する。
初期値masterでは送信しない。通常ユーザーを選んだ後でもmasterへ戻せる。
Webと同じ通常ユーザーを選ぶと、そのIDで履歴を送信する。
「視聴履歴を送信しない」スイッチを追加し、オンの場合は通常ユーザーでも送信しない。
初期値はオフ。ユーザー選択と送信しない設定は接続先ごとに保存する。
