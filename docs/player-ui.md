# ネイティブプレイヤーの操作画面

## 配置と操作

ユーザー指定の配置をSwift / UIKitで実装し、VLCの再生と既存のコメント描画・PiP合成を再利用する。

- 左上：サイドメニュー、録画詳細への戻り。横画面では局ロゴ、小さい局名と番組名も表示する。
- 右上：番組情報、PiP、コメント設定、プレイヤー設定。縦画面も動画内の1段に収める。
  右上・右下・回転ボタンと、左上のメニュー・戻るアイコンにも中央と同じ小さい影を付ける。
- 中央：30秒戻し、10秒戻し、大きな塗りつぶしの再生／一時停止、10秒送り、30秒送り。
  太いスキップアイコンに小さい影を付け、ボタン背景は透明にする。上下の操作欄には帯状の背景を付けない。
- 下部：時間表示と、採用した試作をベクター化した回転アイコン、3ptのシークバーと通常12ptのつまみ。
  回転アイコンは角丸の斜めの端末と曲線の矢印を組み合わせ、矢印の先端を開いた山形にする。
  回転アイコンの描画枠は32ptとし、24ptの通常アイコンより一回り大きく表示する。
  横画面ではその下の右側にリロード、ルール、字幕。縦画面ではこの3ボタンを省略し、
  ルールは動画下のタブ、字幕はプレイヤー設定から操作する。動画の再読み込みは横画面の操作欄と全般設定の一番下に置く。
- 再生時間を押すと経過／残り表示を切り替える。動画の背景タップで操作欄の表示／非表示を切り替える。
  TS・エンコード済みともVLCの映像出力にはタップを渡さず、アプリ側で受け取る。背景タップでは再生状態を変えない。
  最後の操作から2.5秒で自動非表示にする。再生中・一時停止中、横画面の情報パネル表示中にも適用する。
  自然終了では操作欄を表示し、自動非表示だけを止める。終了後もタップで切り替えられる。
  表示／非表示には120msのフェードを使い、途中の再タップにも追従する。
  時間表示はグレーの半透明背景を使う。横画面の下部操作欄はセーフエリアの下端へ寄せる。
  ボタン・シークバー・情報欄へのタップを背景タップと区別し、ドラッグ中・メニュー操作中は自動非表示を保留する。
  設定から自動非表示を無効にできる。下部の情報タブの内容切り替えには移動アニメーションを付けない。
- 情報・ルールのパネルは横画面では右側の約1/3（230〜420pt）を使い、映像を残りの領域へフィットさせる。
  縦画面では初期状態から動画の下に番組情報を表示する。動画はステータスバー直下の16:9領域に配置し、
  余分なタイトル欄を動画上部に設けない。動画下の配色・本文・72ptの下部タブはWebのモバイル版を基準にする。
  横／縦の移行で再生セッションを作り直さない。
  下部タブは番組情報・ルール・コメント・設定とし、設定画面でも表示する。
  アイコンと文字はそれぞれ固定の表示枠に配置し、初回表示・選択・回転でも上下位置を揃える。
  パネルの閉じるボタンは横画面だけ表示し、字幕設定タブの文字と同じ横位置に置く。縦画面では表示しない。
- 右方向のスワイプは縦画面では通常画面と同じ上40％がサイドメニュー、下60％が録画詳細への戻り。
  横画面ではどの高さからでもサイドメニューを開く。画面左端からの開始に限定しない。
  縦スクロール・シークバー・スイッチ操作と区別し、戻る操作は完了したドラッグだけで実行する。
- 手動の回転は横向き（landscapeRight）／縦向きを固定する。
  プレイヤー設定から端末の向きに合わせる状態へ戻せる。
  プレイヤー以外は縦画面限定とし、終了・サイドメニューからの移動・関連録画への移動では縦向きに戻す。
  終了時の対応方向変更と、終了後のウィンドウシーンへの縦向き要求を行う。
- リロードはVLCを停止してから同じファイルを再開し、位置、再生／一時停止、速度、通常字幕選択を引き継ぐ。
  コメントのタイムライン・設定は保持する。PiP中のリロードはPiPを閉じてから行う。
- プレイヤー設定の速度は0.5〜2倍、PLAYのネットワークキャッシュは1〜30秒。
  キャッシュ変更は次のリロードから適用する。これらの追加設定は今回の再生セッション内で扱う。
  巻き戻し用の保持キャッシュは別設定で、オフ／30秒／1〜5分（初期値1分）。変更をその場で適用し、次回へ保存する。
  一時ファイルは明示的な終了時に削除し、新しい再生で以前の残存分を清掃する。画面ロックや時間経過では削除しない。
  再生中はバックグラウンドで音声と入力を維持し、自動PiPを試みる。PiP開始待ち・失敗で再生を止めない。
  PiPなしの一時停止状態からの復帰では読み取り接続とVLC入力を再作成する。停止位置の復元はシーク前に停止する。
  Web視聴履歴の送信設定は維持する。
  全般に「コメントの準備を待って再生」を追加し、次回の再生へ保存する（初期値オフ）。
  オンの場合はコメントの取得・解析・行配置・文字画像を待つ。コメントなし／非表示では待たず、上限15秒で開始する。
- 全般・コメント・字幕は同じプレイヤー設定パネルで切り替える。横画面では右側、縦画面では動画の下に表示する。
  見出しの下に全般・コメント・字幕の固定タブを横一列で置き、選択中だけテーマカラーにする。
  その下の内容を縦にスクロールする。
  操作欄のコメント・字幕ボタンも対応する設定を直接開く。
  コメント設定には表示、文字サイズ、不透明度、トラック選択、再読み込みと状態を移す。
  文字サイズ・不透明度・表示設定は通常画面とPiPのコメント合成に反映する。
  この3項目はUserDefaultsへ保存し、パネルの再表示、別の録画再生、アプリの再起動でも前回の値を引き継ぐ。
  不透明度未指定時はASSに従い、操作後は100%を完全な不透明とする絶対値を使う。
  字幕候補から弾幕と判定されたトラックを除き、通常字幕は元のトラック番号で選択する。
  「字幕なし」または選択名を保存し、次回の再生で同名トラックを復元する。
  該当名がない時は無関係な字幕を選ばない。未設定の時だけVLCの初期選択に従う。
- PiP開始アイコンはSF Symbolsの`pip.enter`を使う。24ptの描画枠で、縦横比を保って最大24ptに収める。
  PiP中は元の映像を黒い案内表示で覆い、
  「ピクチャインピクチャで視聴中」を表示する。中央操作はPiP中だけ隠し、案内と重ならないようにする。
  映像出力とコメント合成を維持し、PiP終了で元の画面へ戻す。
- ホームとプレイヤーは同じ`NeoSidebar`を使う。見出し・行の左位置をセーフエリアに揃え、
  ロゴを見出しの7pt隣に配置する。通常24pt、アニメ27ptのアイコンを共通に使う。
  横画面の映像は左右のセーフエリア内へフィットさせ、情報欄やサイドメニューを開いてもノッチ領域へ入れない。
  映像領域はホームインジケーターの下端まで伸ばす。
  下部操作欄はビルド64から横画面で10pt下げる（画面下端に当たる場合は移動量を抑える）。
  縦画面ではつまみが欠けない2ptの移動とし、中央ボタンは縦横とも5pt下げる。映像の配置は変えない。

## 本体との対応

以下のNeoEPGStation本体のソースを確認した。

- `client/src/pages/RecordedWatchPage.tsx`：ProgramPanel、RulePanel、CommentPanel、パネルのタブと配置。
- `client/src/components/AppLayout.tsx`：240pxのメニュー、見出し・ロゴ・行の余白。
- `client/src/core/player/useTouchPlayerControls.ts`：背景タップによる表示切り替えと、操作ボタンへのタップとの区別。
- `client/src/core/media/recorded.ts`：関連録画のルール優先検索と番組名からのキーワード抽出。
- `client/src/core/player/RecordedPlayerCore.ts`：リロード時の再生位置と一時停止状態の維持。
- `client/src/core/program.ts`：大ジャンル／小ジャンルの表示名。
- テーマ定義とMaterial UIのアイコン定義：既存のターコイズ・ダーク配色と対応アイコン。

番組情報には局名・ロゴ、番組名、日時、概要、ジャンル、番組内容を表示する。
ルールは対応する条件の関連録画を最大100件取得し、Webと同じ順序で表示する。
関連録画を選ぶと再生を終了し、その録画の詳細を同じ録画済みタブに開く。
コメント一覧は既存ASSから読み取った時刻と本文を表示し、再生位置を追従する。
手動スクロールで追従を止め、ボタンで現在位置に戻す。コメント行のタップでその位置へシークする。
コメント字幕がない場合は「コメント字幕がありません」を表示する。

## 現在の範囲と差異

今回の再生経路は録画ファイルのPLAY。STREAMINGと放映中は後続の実装対象。
通常字幕のVLC選択と専用コメント描画の設定を、同じプレイヤー設定パネルから操作する。
コメント付きPiP合成は維持する。通常のVLC字幕をPiPへ合成する機能はまだ対象外。
ユーザー指定により、WebパネルのTwitterタブはアプリでは設定タブに置き換える。
局ロゴが取得できない場合はロゴを表示せず、局名と番組名を詰めて配置する。

シミュレーターでは合成動画で初期の縦画面、レイアウト、ボタン接続、リロードと回転固定を検証する。
実際の向きの画面をUIKitの画面描画で撮影し、一時停止中の塗りつぶし再生アイコンと小さいつまみも確認する。
実サーバーの録画、長時間視聴、LiveContainer上の回転固定とPiP復帰は実機で確認する。
