# 予約機能の移植

| Web の参照元 | iOS の動作 |
| --- | --- |
| ReservesPage、core/reserves | 予約・競合・重複・除外の件数と一覧、ユーザー絞り込み、ページ送り、予約情報更新、個別・一括操作。取得失敗時は再試行でき、更新失敗時は取得済みの一覧を表示する。 |
| AppLayout、`GET /reserves/cnts` | サイドメニューの「予約」の直下に1件以上ある競合・重複だけを件数付きで表示する。タップで該当タブに移動し、一覧を横にスワイプしたときもハイライトを同期する。画面端のスワイプは既存のナビゲーションに渡す。 |
| ReserveProgramDialog | 放送局と番組内容、予約状態とユーザーを表示する。手動予約は詳細画面へ、ルール予約は編集と録画済み検索へ移動できる。 |
| GuideProgramDialog、core/storage/guide の簡易予約設定 | 検索結果からユーザーとTSまたはエンコードプリセットを選んで登録する。TS時はチェック項目が無効になり、録画方式とチェック項目はサーバーごとに保存する。成功後は検索結果と予約一覧を再取得する。 |
| ManualReservePage、core/storage/manualReserve | 新規作成と手動予約の更新、末尾切れ、保存先、ファイル名、エンコード3枠と時刻指定。保存後は元の画面へ戻る。時刻指定の日時は端末のタイムゾーンで解釈する。 |

予約一覧は汎用更新通知を受けて再取得し、行の反映はスクロールが止まってから行う。番組表の時刻への移動は、iOSの番組表画面を実装する段階で接続する。詳細予約の編集内容は画面を開いている間保持する。

Actions の program-search でTSの送信内容、エンコード設定、時刻指定の変換を検証する。iPhone・iPadでは検索からの登録、予約一覧からの手動予約更新、一括キャンセル、詳細予約の新規登録を模擬サーバーで通す。長い番組情報を含む詳細予約の幅と、サイドメニューの件数・タブ移動も確認する。
