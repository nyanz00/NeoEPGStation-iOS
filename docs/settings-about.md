# 設定の統合・アプリ情報・選択欄

- 設定の順序は全般、視聴、表示、アカウント、Annict、Discord、アプリについて。旧アプリ設定の接続先とナビゲーションを全般へ統合する。保存キーは変更しない。
- アプリについては最下段。アプリ名・バージョン・ビルド番号をBundleの実情報から表示し、公開ソースコードへのリンクと使用ライブラリ・ライセンスの閲覧を置く。対応iOSは表示しない。
- Xcodeの両SDKでlicensesフォルダーとTHIRD_PARTY_NOTICES.mdを含める。IPAには従来の詳細なThirdPartyNoticesも引き続き同梱し、画面から文書を開ける。
- 優先字幕はWebのSubtitlePriorityControlと同じく初期3欄、末尾追加、4欄目以降の削除に対応する。保存時と読み込み時のprefix(3)を廃止し、追加した欄も優先順の照合に使う。通常字幕に一致がなければオフという規則は維持する。
- 選択欄はWeb設定のMUI small outlined Selectを参照し、白い選択値、右端のArrowDropDown、白23%の枠とテーマの角丸6ptで描く。選択メニューと選択処理はUIMenuを維持する。設定、再生エンジン、チェックポイント、プレイヤーの画質・キャッシュへ共通部品を使う。配信ダイアログのWeb standard型の下線付き欄とユーザー選択の既存outlined型は維持する。
- 視聴の「コメントを表示」はplayer.comments.enabledを共有する。設定画面から生存中の描画器へ反映し、プレイヤーでの変更も同じキーへ保存する。トラック選択や文字サイズは変更しない。表示変更だけで文字サイズ・不透明度を再適用しない。

対象検証はplayer-feedback。モデルでは3欄初期値、5欄保存、4欄目の選択、追加欄の削除・順序、先頭3欄の保護、表示キーの互換性を確認する。iPhone/iPadでは追加・入力・削除の実コントロール、表示の双方向反映、全般への統合、最下段のアプリ情報・実バージョン、ライセンス同梱と読み取り、枠付き欄と既存メニューの接続を確認する。
