# Swift版UIの移植基準

## 基準

NeoEPGStationの現行Web実装を画面ごとに照合して移植する。
配色だけでなく、配置・情報の表記・余白・アイコン・省略表示・操作の入口を合わせる。
iPhoneの下部ナビゲーションと合意済みのジェスチャーは追加する。
初期配色はターコイズのダークモード。選択色はテーマのアクセント色を使う。

## モバイルのページ切り替え

Webの `client/src/components/VueCompatiblePagination.tsx` の
`mobileItems` とボタン表示を基準とする。

- 左矢印、最大5個の連続したページ番号、右矢印を横一列で中央に置く。
- 番号を押すと該当ページへ直接移動する。
- 先頭では1〜5、中間では現在ページを中央にする。7ページ目なら5〜9。
  末尾では最後の5ページに寄せ、全体が5ページ未満なら存在する番号だけを出す。
- 現在ページの背景だけをアクセント色にし、他は暗い角丸ボタンにする。
  矢印も同じ形と大きさにする。先頭・末尾では対応する矢印を無効表示にする。
- 全体が1ページ以下ならページ切り替えを出さない。
- Webと同じく一覧の末尾に置き、一覧と一緒にスクロールする。
  下部ナビゲーションとは別の要素として扱う。
- 現行試作の「前へ／表示件数の範囲／次へ」の固定フッターは移植しない。

iPadの番号表示数・省略記号はWebの幅に応じた規則を基準とし、
モバイル用の5番号表示とは区別する。

## 録画カード

Webの `client/src/pages/RecordedPage.tsx` の `RecordedCard` を基準とする。

- モバイルは左サムネイル、右に番組名・放送局・放送時間・説明を配置する。
- 番組名の右側に縦三点の録画メニューを配置する。
- 日時の短い表記、曜日、終了時刻、番組時間をWebの規則に合わせる。
  年・秒を含む端末既定の日時表記へ置き換えない。
- 文字の太さ・色、行の省略、画像の切り抜き、角丸、余白をWebと照合する。
- メニュー項目や詳細画面は機能の移植に合わせて実装する。

## 確認

Swift版の画面画像をWebの同条件の画面と比較する。
起動・画像の生成に加え、実機でメニューの指への追従と画面切り替えの応答を確認する。
React Native試作の画面画像は完成デザインの基準にしない。
