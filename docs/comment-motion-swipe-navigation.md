# コメントの時計・動画スワイプ・検索からの復帰

## 動作

- 最初のコメント表示は、映像が供給され、VLCの再生時刻が進み始めた後に行う。
- 新しいコメントの出現判定には動画時刻を使う。表示中のコメントは独立した単調な時計で動かし、通常の動画時刻の補正で止めたり位置を戻したりしない。移動時間5.25秒は維持する。
- 実際の停止・バッファ待ちでは移動時計も停止する。ユーザーのシークでは表示対象をリセットし、移動先のコメントを用意する。
- 初期範囲から全件への切り替えでは、表示中のID・移動開始時刻・配置を引き継ぐ。配置計算は表示対象またはサイズが変わった時だけ、表示中の文字画像の寸法と実際の移動時間を使って行う。
- 動画部分を縦画面で上へスワイプすると、動画の下端と下の情報パネルを固定して上へ拡大する。動画上端から画面上端までの余白分だけ指を動かすと、時計・インジケーターの領域まで動画が達し、指を離す前に横画面へ切り替える。画面下部まで拡大しない。
- 横画面で下へスワイプすると、動画サイズを維持して指の移動量だけ下へ動かす。上端が画面高の35％に達したら縦画面へ切り替える。移動量に上限を設けず、速度だけで早期に切り替えない。
- 縦横の切り替えでは、所有する子コンテナでUIKitの回転を打ち消し、実際の動画とUIを独自に回転・配置する。時間は標準回転の80％、最大280ms。コントローラーのルートビューは変更せず、システム回転の完了時に同じ最終配置へ戻す。入力やPiPの表示面は再生成しない。「視差効果を減らす」では10msとする。
- スワイプ開始時は操作UIを隠す。キャンセルや回転要求の失敗では元に戻す。入力の再読み込みは行わない。
- 録画詳細への右スワイプは、ドラッグ開始時からUIKitの対話的な終了遷移を開始し、画面幅に対する指の移動量を進捗に反映する。28％の距離または450pt/sを超えて離すと完了し、未到達・キャンセルでは元へ戻す。キャンセル時はVLC入力とキャッシュを維持する。戻るボタンは同じ右方向のアニメーターにease-outを使用する。
- UIKitの遷移コンテキストが準備される前に届いた進捗・完了・キャンセル指示は保持し、コンテキスト開始後に反映する。短いドラッグでも終了指示を失わない。
- 終了遷移が成功した後にVLC・コメント・キャッシュを終了する。画面の動きをVLC停止完了待ちで遅らせず、停止通知が来るまでプレイヤーとdrawableを保持する。終了・別ページへのコールバックはネイティブ停止後に通知する。
- ボタン・シークバー・情報パネルは動画スワイプの対象にしない。横方向のサイドメニュー・戻る操作は維持する。
- 録画済みボタンは、検索から開いた詳細 → 検索結果 → 検索前の一覧 → 1ページ目の順に戻す。検索前の一覧は同じインスタンスを使い、ページとスクロール位置を保持する。

## 検証

ネイティブテストで開始待ち、100msの後方時計補正、停止・再開、速度変更、明示的なシーク、全件切り替え、実際の移動時間による衝突判定を確認する。シミュレーターでMetal/CPU合成、スワイプの追従・キャンセル・方向別ルーティング、検索結果からの連続ナビ操作を確認する。

`comments.initialAnchor` は、初回のコメント時計が実際の動画時刻へ合った時点を診断ログへ記録する。実機での開始直後の滑らかさと、回転アニメーションの操作感はシミュレーター検証とは区別する。
